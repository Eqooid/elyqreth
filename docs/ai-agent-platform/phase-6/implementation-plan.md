## Production acceptance gates

1. **Access:** chosen audience, production principal/object authorization, private/public owner isolation and browser session/CSRF/origin tests pass; current dev-only restrictions are not bypassed.
2. **Network/config:** no direct public API/DB/admin exposure, trusted TLS/CA/proxy/egress, least-privilege rotated server secrets, safe static artifact/config/caching and readiness pass.
3. **Durability:** compatible migrations, protected off-host backup and independently measured restore, uncertain-effect handling and exact idempotency survive restart/deploy.
4. **Execution:** one active native writer/admission policy, safe drain/cancel/timeout/lease behavior, no duplicate work or new execution authority; external provider remains authoritative.
5. **Operations:** bounded resource/load/cost evidence, working alerts, approved RPO/RTO/retention, tested runbooks and named responders exist.
6. **Release:** immutable artifact promotion, actual staged rehearsal, rollback limits, explicit production approval and required live reference evidence pass; version/release only by authorized procedure.
